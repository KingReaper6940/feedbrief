    What this inspector checks — and what it leaves out

    Supported: unqualified RSS version 2.0 with exactly one channel, or an Atom feed in http://www.w3.org/2005/Atom. Core direct children only; extensions are ignored. Selected first fields are extracted with JavaScript trim. For Atom links, the first rel=alternate (or no rel) is selected regardless of language/type. RSS guid is treated as an identifier, not an automatically followed permalink.

    Receipts cover selected missing/empty fields, repeated entry title/ID/date elements, duplicate trimmed IDs, shared resolved HTTP links and missing/unresolved selected links. RSS optional fields are notes. This does not check complete required-field rules, date syntax, authors, enclosures, podcast requirements, HTML semantics, ID validity or reader behavior. Link resolution uses the browser URL implementation; non-HTTP schemes and credentials are deliberately unsupported, not declared invalid by feed standards.

    Max 5,000 elements and depth 32. DTD/entity declarations and stylesheet instructions are rejected, even if mentioned in comments. Preview fields are clipped with an explicit omitted-character count; JSON and Markdown contain the full extracted values. Ten entries per page, first 100 findings shown with omissions disclosed. No automatic cleanup or source modification.

    No application storage, uploads or analytics. Your browser may restore a tab; local text inputs are not a guarantee against browser caching. Native browser visual/responsive checks, download destination checks and a real screenshot are pending; simulated DOM tests do not verify rendering.
